# Unsaid（未尽）

一款检索式情感陪伴应用。基于你和 TA 的真实聊天记录,用 TA 说过的原话来回应——不依赖大模型生成,每句都来自真实对话。

> 陪你把没说完的话说完。

## 项目结构


## 快速开始

### 网页版(单人测试)

直接用浏览器打开 `web/index.html`。填昵称 → 底部"以谁的身份说"切换,一个人扮演双方攒记录 → 右上 ⋯ 进"回忆模式"或导出。数据存浏览器 localStorage。

### 小程序版

用微信开发者工具导入 `miniprogram/` 目录,AppID 选测试号即可预览。

## 数据存储(当前 & 规划)

- **当前**:网页版存浏览器 localStorage;小程序存 wx storage。均为本机、不上传。
- **规划**:联网双人版 → Firebase 实时数据库(网页)/ 小程序云开发。代码已预留同步接口(`sendToServer()` / chat.js send 内的推送位)。

## 核心逻辑:检索式匹配

`utils/retrieval.js`(小程序)与网页版内联脚本一致:

- 把消息序列构建为"我说的话 → TA 回复"配对。
- 用户输入时,以"双字 + 单字"混合 Jaccard 相似度检索最接近的历史提问,返回当时 TA 的真实回复。
- 相似度低于阈值(0.12)则触发兜底,并如实提示"记录里没有相近的话"——纯检索的固有局限。
