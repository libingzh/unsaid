# 这份指引帮你做什么

你已经有了 `未尽_app.html` 这个 app 文件。它本身写好了全部功能,但"两台手机实时聊天"需要一个免费的在线后端来同步消息。我们用 **Firebase**(Google 的免费服务),你不用写任何代码,只要跟着下面点几下、粘贴一段配置就行。全程大约 15 分钟。

如果你暂时不想配置,直接双击打开 `未尽_app.html`,点"先体验单机演示"也能先感受流程(只是不能两台手机联网)。

---

# 你会用到的三样东西

1. 一个 Google 账号(没有就先注册一个)。
2. 电脑上的 `未尽_app.html` 文件。
3. 一个纯文本编辑器(Windows 的"记事本"、Mac 的"文本编辑"都行)。

---

# 第一步:创建 Firebase 项目(约 5 分钟)

1. 用浏览器打开 **https://console.firebase.google.com** ,用 Google 账号登录。
2. 点 **"创建项目 / Add project"**。
3. 给项目起个名字,比如 `weijin`,一路点"继续 / Continue"。中间问"是否启用 Google Analytics"选**关闭**即可,更简单。
4. 等它创建好,点"继续"进入项目主页。

# 第二步:开启"实时数据库"(约 3 分钟)

1. 在左侧菜单找到 **"构建 / Build" → "Realtime Database(实时数据库)"**。注意别选成 "Firestore",要选 **Realtime Database**。
2. 点 **"创建数据库 / Create Database"**。
3. 位置随便选一个(如新加坡 asia-southeast1),点下一步。
4. 安全规则选 **"以测试模式启动 / Start in test mode"**,点"启用"。
   （测试模式方便你们先用起来;它是临时开放的,第五步会教你改得更安全。）

# 第三步:拿到你的"配置"(约 3 分钟)

1. 点左上角 **齿轮图标 ⚙ → "项目设置 / Project settings"**。
2. 往下滚到 **"你的应用 / Your apps"**,点 **`</>`(网页)** 图标。
3. 起个昵称(如 weijin-web),点"注册应用"。**不用**勾选 Firebase Hosting,点下一步跳过即可。
4. 它会显示一段 `const firebaseConfig = { ... }` 的代码。这就是你要的配置。把整段里花括号 `{ }` 中间的内容记下来(下一步要用)。
5. 还需要一个数据库网址:回到"实时数据库"页面,顶部有一行形如 `https://weijin-xxxx-default-rtdb.firebaseio.com/` 的网址,复制它。

# 第四步:把配置填进 app 文件(约 3 分钟)

1. 用**记事本 / 文本编辑**打开 `未尽_app.html`(右键 → 打开方式 → 记事本)。
2. 用查找功能(Ctrl+F / Cmd+F)搜 `firebaseConfig`,找到这一段:

```
const firebaseConfig = {
  // apiKey: "粘贴你的",
  // authDomain: "粘贴你的",
  ...
};
```

3. 把每一行前面的 `//` 删掉,并把引号里的内容换成你第三步拿到的真实值。最后一行 `databaseURL` 填第三步复制的数据库网址。改完大概长这样(仅示例,用你自己的值):

```
const firebaseConfig = {
  apiKey: "AIzaSyXXXXXXXX",
  authDomain: "weijin-xxxx.firebaseapp.com",
  projectId: "weijin-xxxx",
  storageBucket: "weijin-xxxx.appspot.com",
  messagingSenderId: "1234567890",
  appId: "1:1234567890:web:abcdef",
  databaseURL: "https://weijin-xxxx-default-rtdb.firebaseio.com"
};
```

4. 保存文件(Ctrl+S / Cmd+S)。**保持后缀是 .html**(记事本另存为时,把"保存类型"选"所有文件",编码选 UTF-8)。

# 第五步:让两台手机都能打开(二选一)

app 需要放到网上,两台手机才能用同一个链接打开。最简单的免费方式:

**方式 A:Firebase Hosting(推荐,免费且和你项目同源)**

需要在电脑装一点工具,若你完全不想碰命令行,用方式 B。

**方式 B:免费静态托管(最省事,零命令行)**

1. 打开 **https://app.netlify.com/drop**(Netlify Drop,免费)。
2. 直接把你的 `未尽_app.html` 拖到网页上。
3. 几秒后它给你一个网址(如 `https://xxxx.netlify.app`)。把文件名换成 `index.html` 再拖,链接更干净。
4. 把这个网址发给对方,两人手机浏览器打开即可。

> 小提示:也可以先在自己电脑上双击 html 直接测试联网聊天(两个浏览器窗口、同一个房间号),验证通了再托管。

# 第六步:开始使用

1. 两人各自打开网址。
2. 各自填**昵称**,以及**同一个房间号**(比如约定好 `xiaolu-2026`,两人必须一模一样)。
3. 点"进入聊天",就能实时聊了。消息会自动存到你的 Firebase。
4. 聊一段时间后,点右上角 **⋯** 菜单:
   - **这段时间的记录**:看攒了多少条。
   - **切换成"回忆模式"**:用你们攒下的真实对话,和"过去的 TA"检索式对话。
   - **导出 txt / json**:随时把记录导出成文件,喂给之前的检索式工具或留存。

---

# 关于隐私与安全(重要)

- 测试模式的数据库任何人知道网址都能读写。你们**私下用、房间号别设成好猜的**基本够用;若要更稳,在"实时数据库 → 规则"里把规则改为需要登录,或设定只有特定房间可读写(需要时我可以给你具体规则)。
- 你们的聊天存在你自己的 Firebase 项目里,由你掌控,可随时在控制台删除。
- 这是你们双方自愿、用于个人纪念的项目,聊天记录都是你们本人的,不涉及第三方隐私。

# 卡住了怎么办

任何一步卡住,把你看到的页面截图发我,我按你的实际界面一步步教。最常见的两个坑:① 数据库选成了 Firestore(要选 Realtime Database);② 保存 html 时被记事本加了 .txt 后缀(要确保结尾是 .html)。
